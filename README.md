# Arsalan Alam — Portfolio

My personal portfolio site, built to showcase my projects and background as a Computer Engineering undergrad focused on backend and systems development.

**Live site:** [arsalanalam.netlify.app](https://arsalanalam.netlify.app)

## Overview

A single-page portfolio covering:
- About & education
- Technical skills (languages, web, concepts)
- Software projects (C++, Java, Python, SQL)
- Hardware/embedded projects (Arduino Uno)
- Contact links

## Built with

- HTML5, CSS3, vanilla JavaScript — no frameworks
- Google Fonts (Space Grotesk, Inter, IBM Plex Mono)
- Font Awesome (icons)
- Deployed on [Netlify](https://netlify.com)

## Features

- Fully responsive layout (mobile → desktop)
- Scroll-based active nav highlighting via `IntersectionObserver`
- SEO metadata: Open Graph tags, Twitter Card tags, JSON-LD structured data
- Custom "schema/record" visual theme tying the design to a backend/database focus

## Project structure

```
.
├── index.html
├── style.css
├── script.js
├── logo.png
├── My_Photo.png
├── Arsalan_Alam_Resume.pdf
└── README.md
```

## Running locally

No build step — just open `index.html` in a browser, or serve the folder with any static server:

```bash
python3 -m http.server
```
